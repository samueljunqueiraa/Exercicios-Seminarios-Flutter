# 📱 Exercícios e Seminários Flutter (Projeto Final)

Este repositório contém o **Projeto Final** e os exercícios práticos desenvolvidos para a disciplina de Seminários de Flutter. A aplicação demonstra o uso do framework para a criação de interfaces modernas, performáticas e multiplataforma.

---

## 🚀 Funcionalidades e Aprendizados
* **Desenvolvimento Multiplataforma**: Código único rodando em Android, iOS, Web e Desktop (Windows/Linux/macOS).
* **Gestão de Estado**: Implementação de fluxos de dados dinâmicos utilizando as melhores práticas do ecossistema Flutter.
* **UI/UX Nativa**: Interfaces construídas com widgets seguindo os guias do Material Design e Cupertino.

---

## 🛠️ Tecnologias Utilizadas
* **Linguagem**: Dart.
* **Framework**: Flutter.
* **Ferramentas**: Análise estática via `analysis_options.yaml` para garantia de qualidade de código.

---

## 📁 Estrutura do Projeto
O projeto segue a estrutura padrão do Flutter, separando a lógica de negócio das configurações de plataforma:

```
Exercicios-Seminarios-Flutter/
├── lib/                        # Código fonte Dart (Lógica e UI)
├── test/                       # Testes unitários e de widget
├── android/ | ios/ | web/      # Configurações nativas por plataforma
├── windows/ | linux/ | macos/  # Suporte para Desktop
└── pubspec.yaml                # Dependências e assets do projeto
```

## 📥 Como Executar
Pré-requisitos
Flutter SDK instalado e configurado.

Emulador ou dispositivo físico conectado.

### Execução:
```
# Clone o repositório
git clone [https://github.com/samueljunqueiraa/Exercicios-Seminarios-Flutter.git](https://github.com/samueljunqueiraa/Exercicios-Seminarios-Flutter.git)

# Obtenha as dependências
flutter pub get

# Execute a aplicação
flutter run
```
